# Bookstore Database Analysis Using SQL

## Project Overview
This project focuses on analyzing bookstore data using SQL and PostgreSQL. I created database tables, imported CSV datasets, and solved basic to advanced SQL queries to answer practical business questions.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Dataset Description
This project uses three CSV files:

- **book.csv:** Book ID, title, author, genre, published year, price, and stock.
- **customer.csv:** Customer ID, name, email, phone, city, and country.
- **orders.csv:** Order ID, customer ID, book ID, order date, quantity, and total amount.

## SQL Concepts Used
- SELECT and WHERE
- JOIN
- GROUP BY and HAVING
- Aggregate Functions: SUM(), AVG(), COUNT()
- DISTINCT
- ORDER BY and LIMIT
- Primary Keys and Foreign Keys

## Project Workflow
1. Created database tables using SQL.
2. Imported data from CSV files using pgAdmin.
3. Checked the imported data.
4. Solved basic and advanced SQL questions.
5. Analyzed book sales, customer orders, stock, and revenue.

## Business Questions Solved
- Retrieved books belonging to a specific genre.
- Found books published after a particular year.
- Filtered customers by country.
- Calculated total stock and total revenue.
- Identified the most expensive book.
- Calculated books sold by genre and author.
- Found customers with at least two orders.
- Identified the most frequently ordered book.
- Analyzed customer spending.

## Key Learnings
- Practical experience with relational databases.
- Data retrieval and filtering using SQL.
- Combining multiple tables using JOIN.
- Summarizing data with aggregate functions.
- Grouping and analyzing data to answer business questions.
